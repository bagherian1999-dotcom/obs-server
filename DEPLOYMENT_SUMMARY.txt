HOW TO USE
=============================================================

Quick Start (3 commands):

  2. ./setup-ssl.sh (optional, for SSL)
  3. Access: http://YOUR_IP:8080

Production Deployment:
  1. ./deploy.sh (configure with domain & SSL)
  2. ./setup-ssl.sh (choose Let's Encrypt)

  4. Access: https://yourdomain.com

Docker Deployment:
  1. cp server/config.json.example server/config.json
  2. Edit server/config.json
  3. docker-compose up -d

=============================================================
NEXT STEPS
=============================================================

To deploy your server:

1. Run the deployment script:
   $ ./deploy.sh

2. Follow the prompts to configure:
   - Server IP (use 0.0.0.0 for all interfaces)
   - Port (8080 for HTTP, 443 for HTTPS)
   - Domain name (optional)
   - SSL (yes for production, no for testing)

3. If using SSL, run SSL setup:
   $ ./setup-ssl.sh

4. (Optional) Install as system service:
   $ sudo ./install-as-service.sh

5. Access your server:
   - HTTP: http://YOUR_SERVER_IP:8080
   - HTTPS: https://YOUR_DOMAIN:443

TESTING THE SETUP
=============================================================

You can test locally without deploying:

1. Create a test configuration:
   $ cp server/config.json.example server/config.json

2. Edit server/config.json (use defaults for testing)

3. Build and run (requires Go):
   $ cd server
   $ go mod tidy
   $ go build -o gosync-server main.go config.go
   $ ./gosync-server

4. Access at: http://localhost:8080

=============================================================
SECURITY CHECKLIST FOR PRODUCTION
=============================================================

Before deploying to production, ensure:

□ SSL/HTTPS is enabled
□ Using Let's Encrypt or proper CA certificates
□ Firewall is configured (allow ports 80/443)
□ Server binding to correct interface
□ Data directory has proper permissions
□ Regular backups are configured
□ Certificate auto-renewal is set up (Let's Encrypt)

=============================================================
TROUBLESHOOTING
=============================================================

Port already in use:
  $ sudo lsof -i :8080

Check server status (if using systemd):
  $ sudo systemctl status gosync

View logs:
  $ sudo journalctl -u gosync -f

Test configuration:
  $ cat server/config.json
